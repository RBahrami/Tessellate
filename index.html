LayersClick a layer to edit it in the sections below. The Background layer is pinned to the bottom — it cannot be deleted or reordered. Every pattern layer keeps its own tiling, colors, effects and animation; exports render the whole stack. Randomize layer (and the 🎲 buttons in each section) act on the selected layer only.
Tiling Picks the tiling family, variant, scale, rotation, gap, outlines and the random seed for the selected layer. Fill transparency and border transparency are separate, so tiles can be faded independently of their wireframe. Changing family keeps this layer's colors; other layers are never touched.
Color theme Every mode keeps its own arrangement, settings and templates; edits apply to the selected layer live. Auto outline picks a border color from the palette/background; uncheck it to set a manual border color. The wallpaper background lives on the Background layer (see the Layers section). Saved templates and custom palettes/gradients persist in the browser and travel with the theme export/import files.
Background layerThe Background layer is always at the bottom of the stack. It supports a solid color or a fully editable gradient (type, angle, stops) and never depends on the selected pattern layer. Hide it (eye icon in Layers) or set opacity below 100% to export PNG/APNG wallpapers with real transparency.
Visual effects Effects apply to the selected layer only — in the live preview and in every export format alike. 0 = off.

Special effects picks ONE effect from the dropdown (Shimmer — frozen tile shades, Sheen, Iridescence, Chromatic aberration, Scanlines); only that effect's settings are shown, and switching to None turns it off. Shimmer is the still frame of the Shimmer animation: each tile gets a shade variant of its own color.

Tessellate

Geometric wallpaper studio · Einstein hat & 13 tiling families · PNG / GIF / APNG / SVG / PSD exports

A studio for the aperiodic Einstein hat monotile (Smith, Myers, Kaplan & Goodman-Strauss 2023 — An Aperiodic Monotile, arXiv:2303.10798) plus a collection of mathematically verified periodic and composite tilings: honeycombs, kagome, octagon–square, Cairo pentagons (dual of the snub square tiling), herringbone, Penrose rhombs (dual of a de Bruijn pentagrid) and more. Stack pattern layers over a background layer, give each its own tiling, colors, effects and animation, then export or share the result.

The project is auto-saved in this browser as you edit. Save downloads it as one JSON file (all layers + custom palettes/gradients) — the format is documented in docs/AGENT_GUIDE.md, so agents can generate wallpapers by writing that file and loading it here. Undo/Redo (Ctrl+Z / Ctrl+Y) reverts any change, including layer operations and randomizers. The Export menu offers PNG, looping GIF, lossless APNG, editable SVG vectors and layered PSD documents — SVG/PSD open an options dialog with appearance presets (outlines only, monochrome, silhouette, grayscale, custom) and a live preview; both are static frames at time zero and never modify your project. Share uses the operating system share sheet when available: PNG while nothing animates, looping GIF otherwise (falls back to a download where sharing is unsupported).
